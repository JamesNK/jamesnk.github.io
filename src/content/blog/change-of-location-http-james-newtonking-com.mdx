This blog is moving to http://james.newtonking.com/.
 
To handle links and traffic going to the old location I've setup a brilliant little HttpModule called [UrlRewritingNet.UrlRewrite](http://www.urlrewriting.net/). It will redirect all traffic to the new address. Hopefully it should help make the transition fairly painless.
