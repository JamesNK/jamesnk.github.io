I've updated the blog to use [Astro](https://astro.build/), a Node.js-based static site generator. Hosting has also changed to GitHub Pages.

## Benefits

- The blog no longer runs on an [ancient version of Orchard CMS](https://github.com/OrchardCMS/Orchard/releases/tag/1.9.1) that I'm afraid to touch.
- Free and reliable hosting for a static site on GitHub Pages.
- Secured with HTTPS, which is essential since browsers [flag non-HTTPS sites as insecure](https://security.googleblog.com/2025/10/https-by-default.html).
- General cleanup of content. A decade of different authoring tools (remember Windows Live Writer?), blog engines, domains, and hosts left a trail of broken images and badly formatted HTML. I vibe-coded a migration tool to convert HTML to Markdown and do its best to fix broken images and links.
- Gain experience with Astro; we (Aspire team) are using it to build [aspire.dev](https://aspire.dev).
- If I ever blog again, I can do it from the comfort of Markdown files in a Git repository.
