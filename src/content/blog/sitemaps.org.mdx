I'm surprised I missed this: [sitemaps.org](http://www.sitemaps.org/)

Google, Microsoft and Yahoo are collaborating together on a sitemap XML format. Because the format is essentially the same as what Google is already using, [GoogleSitemap.NET](http://james.newtonking.com/products/googlesitemap/) can now be used with all the major search engines 😊
